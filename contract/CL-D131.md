## CL-D131 — Review-only runs Sol after a convergence FIX BEFORE MERGE with no Blocker
**Clauses:** CL-D131-record, CL-D131-driver, CL-D131-forward, CL-D131-shared, CL-D131-tests

*Decision ID:* CL-D131
*Kind:* contract
*Target and revision:* `tetsuh/pi-tidd-agents#329` at its body, and the owner's choice of Option A (https://github.com/tetsuh/pi-tidd-agents/issues/329#issuecomment-6551087893)
*Question:* CL-D62 had review-only stop at `WAITING_FOR_OWNER` on a convergence `FIX BEFORE MERGE` before Sol runs, so Sol reviews only a head convergence has passed. On a long pull request the deepest findings came from Sol, each after several convergence-only rounds, and one convergence counterexample stood for runs until Sol corrected it (#329). When does the review-only driver run Sol?
*Options and trade-offs:* Option A runs Sol after a convergence `FIX BEFORE MERGE` with no `Blocker` in the same run and publishes both gates' findings as one round, at the cost of one Sol launch per such run. Option B runs Sol in a pull request's first counted run whatever convergence returns, which moves only the first deep review forward. Option C keeps the order.
*Recommendation:* Option A.
*Owner choice:* Option A. In the review-only driver, when convergence returns `FIX BEFORE MERGE` and none of its open findings is a `Blocker`, Sol is launched on the same head in the same run, with convergence's open findings as unresolved history, not as assigned findings. The run then stops `WAITING_FOR_OWNER` with both gates' findings in one published round, whatever Sol returns, and Terra is not launched in it. A convergence `Blocker`, a `NEEDS DECISION` verdict or a finding that needs an owner decision still stops the run before Sol. The run publishes one round, so it counts once under CL-D110, and Sol's invocation counts toward Sol's per-run cap. Convergence at its cap still hands Sol its open findings assigned (CL-D62). The exact autofix driver's order is unchanged, since its writer corrects convergence findings before Sol.
*Rationale:* The author gets the deep findings with the shallow ones in one round instead of after them, and Sol reads convergence's findings as context it may contradict, not as claims it must confirm, so a wrong convergence premise can be corrected in the same run. A `Blocker` or an owner decision says the head is not worth a Sol review yet.
*Validity and invalidation conditions:* Applies to the packaged review-only driver. Launching Terra in such a run, assigning convergence's findings to Sol before the cap, or changing the exact autofix driver's order requires a new owner decision.
